## Propósito del documento

Este documento describe cómo se utilizó la inteligencia artificial como apoyo
durante el desarrollo del proyecto `analizador-fasta`.

La IA no fue usada para reemplazar el análisis del problema ni para copiar código
sin revisión. Fue utilizada como una herramienta de apoyo para aclarar ideas,
comparar propuestas, revisar buenas prácticas y mejorar la calidad del proyecto.

## Forma en que se utilizó la IA

Durante el desarrollo del proyecto, la IA se utilizó para:

- Implementar las buenas practicas durante todo el ejercicio.
- Que el mensaje de error para archivos inexistentes fuera claro.

- Para que los Docstrings en el codigo fueran lo mas claros posibles.

-para que el archivo README.md fuera lo mas detallado para la comprension de usuario.

El uso de IA en este proyecto fue una colaboración supervisada. La IA ayudó a
organizar ideas, mejorar explicaciones y revisar buenas prácticas, pero las
decisiones finales fueron tomadas después de analizar, probar y aprobar cada parte
del proyecto.
